# MultiTool French

Веб-приложение для работы с французским:

- **Переводчик** RU ↔ FR.
- **Расшифровка** аудио и видео на любом языке (язык определяется сам или выбирается вручную) с переводом на русский и скачиванием в TXT.
- **Конспект** на русском по переводу или расшифровке: главная мысль, разделы с таймкодами, выводы.

Работает на бесплатных уровнях Gemini API (Google) и, по желанию, Groq.

## Как запустить на своём компьютере

Нужен Python 3.10 или новее.

1. Получите бесплатный ключ Gemini: https://aistudio.google.com/apikey
2. (Необязательно) Получите бесплатный ключ Groq для более точной расшифровки: https://console.groq.com/keys
3. Скопируйте `.env.example` в `.env` и вставьте ключи.
4. Установите зависимости и запустите:

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

5. Откройте в браузере http://localhost:8000

Отдельно ставить ffmpeg не нужно: если его нет в системе, используется версия из пакета `imageio-ffmpeg`.

## Как работает расшифровка

1. Из файла (аудио или видео) извлекается звук и режется на части по 10 минут.
   Язык записи определяется автоматически; если ошибся, его можно выбрать вручную.
2. Каждая часть расшифровывается: через Groq (Whisper), если задан `GROQ_API_KEY`, иначе через Gemini.
3. Короткие фразы склеиваются в абзацы по 20–60 секунд.
4. Абзацы переводятся на русский через Gemini пачками.
5. Результат можно скачать в TXT: таймкод, французский текст, русский перевод.

После расшифровки кнопка «Конспект» делает конспект на русском по оригиналу, с таймкодами разделов.
Конспект можно скопировать или скачать в TXT.

Если упёрлись в бесплатный лимит, приложение само подождёт и продолжит, а на странице будет видно, сколько ждать.
Файлы обрабатываются по очереди. Результат хранится в памяти сервера 24 часа и пропадает при перезапуске.

## Настройки (файл `.env`)

| Переменная | Что это |
|---|---|
| `GEMINI_API_KEY` | Ключ Gemini API, обязателен |
| `GEMINI_MODEL` | Модель Gemini; пусто — подбирается автоматически |
| `GROQ_API_KEY` | Ключ Groq, необязателен |
| `TRANSCRIBE_ENGINE` | `auto`, `groq` или `gemini` |
| `MAX_UPLOAD_MB` | Максимальный размер файла, по умолчанию 2000 МБ |
| `APP_PASSWORD` | Пароль для входа на сайт; пусто — без пароля |

Свои бесплатные лимиты Gemini можно посмотреть на https://aistudio.google.com/rate-limit

⚠️ На бесплатном уровне Google может использовать отправленные данные для улучшения своих продуктов. Не отправляйте конфиденциальные записи.

## Как выложить в интернет (Render, бесплатно)

GitHub только хранит код, но не запускает его — для сайта нужен хостинг.

1. Зарегистрируйтесь на https://render.com через аккаунт GitHub.
2. **New → Web Service**, выберите этот репозиторий (Render попросит доступ к нему).
3. Заполните поля:
   - **Branch:** ветка с кодом;
   - **Runtime / Language:** Python 3;
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
   - **Instance Type:** Free.
4. В **Environment Variables** добавьте `GEMINI_API_KEY`, `APP_PASSWORD` и, если есть, `GROQ_API_KEY`.
   Если сборка ругается на версию Python, добавьте ещё `PYTHON_VERSION` = `3.12.7`.
5. Нажмите **Deploy**. Через несколько минут сайт будет доступен по ссылке вида `https://<имя>.onrender.com`.

Особенности бесплатного тарифа Render: сервер засыпает, если к нему 15 минут никто не обращается,
и первое открытие после этого занимает около минуты. Во время долгой расшифровки держите вкладку открытой.
Задачи и конспекты хранятся в памяти и пропадают, когда сервер засыпает или перезапускается — скачивайте TXT сразу.
